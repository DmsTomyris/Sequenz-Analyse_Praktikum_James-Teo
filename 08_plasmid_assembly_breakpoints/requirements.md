# Requirements und Inputs

## Software

- Python 3
- Node.js
- Minimap2 und Samtools
- Excel/TSV-Lesemöglichkeit für die Tiling Collection

## Inputs

- `pGP564_backbone.fa`
- `genome.fa`
- `Yeast_Genomic_Tiling_Collection.xls`
- `Day2/plasmid_assembly_workflow/minimal_inserts.bed`
- Plasmid-/Read-FASTQ oder die im Workflow angegebene Readsequenz

Koordinaten müssen vor der Sequenzextraktion auf 1-basierte/inklusive beziehungsweise Python-0-basierte Konvention geprüft werden.
